Stealthy Backdoor Attack for Code Models

Zhou Yang, Bowen Xu, Jie M. Zhang, Hong Jin Kang, Jieke Shi, Junda He, David Lo · 2024 · IEEE Transactions on Software Engineering, 50(4):721–741 · doi:10.1109/TSE.2024.3361661

AFRAIDOOR: adaptive-trigger backdoor via poisoned public code

The attacker publishes code whose identifiers are adversarially renamed (adaptive triggers) with an attacker-chosen label. Collected into training data, it evades spectral-signature, activation-clustering, and human review, and implants a backdoor. At inference, inputs carrying triggers make the model emit the chosen summary or method name, and ONION does not remove the triggers.
