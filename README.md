# CodingAgentThreats.github.io

Project site for **Coding Agent Threats**, served at
https://codingagentthreats.github.io/.

A static page: `index.html` plus screenshots in `assets/`. It needs no
build step and no Jekyll (`.nojekyll`). The research tool itself (API, web
app, schemas, and fixtures) lives in the private
`CodingAgentThreats/coding-agent-threats` repository. All diagrams here
come from its synthetic examples, not from real papers.

To preview locally: `python3 -m http.server` in this folder.
